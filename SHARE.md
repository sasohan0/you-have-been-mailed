### Option 2: The Tech & Architecture Showcase Angle (For Devs & Engineers 💻)

```text
How I built a 100% self-hosted, serverless email tracker for Gmail with Google Apps Script and Chrome Manifest V3 🛠️

Most tracking extensions rely on heavy external backends, database subscriptions, and third-party servers that read your inbox metadata.

Instead, I designed **You Have Been Mailed** with a completely decentralized, zero-cost architecture:

🔹 Storage Engine: Personal Google Sheets via Google Apps Script (GAS) Web App
🔹 Tracking Pixel: Transparent 1x1 GIF dynamically served from GAS endpoint with `Cache-Control: private, no-store`
🔹 Self-Open Filtering: Uses Chrome's `declarativeNetRequest` to intercept local pixel triggers so your own views never count falsely
🔹 Live UI Injection: Lightweight Gmail DOM observer injects real-time double checkmarks (✓ Sent, ✓✓ Opened, ✉️ Replied)
🔹 Smart Automation: 1-Click threaded auto-bumps and 3-stage drip triggers that respect recruiter replies

Zero npm builds. Zero CDNs. 100% private.

The repository is completely public:
⭐ Star on GitHub: https://github.com/sasohan0/you-have-been-mailed

Feedback and PRs are warmly welcome!
```
